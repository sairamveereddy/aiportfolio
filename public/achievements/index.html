Miro × n8n Hackathon — Winning Team: Strangers

Official Event: Miro × n8n Hackathon: "From Diagram to Automation"

View Complete Case Study →
Organizers Miro & n8n
Award Category Winning Team (1st Place)
Team Name Strangers
Date / Year 2026
Core Technology n8n Multi-Agent + Miro REST API

At the official "From Diagram to Automation" hackathon co-hosted by Miro and n8n, teams were challenged to bridge visual diagramming with automated execution. Our team, "Strangers", engineered a bi-directional event-driven pipeline that ingests live Miro canvas activity, runs an autonomous n8n multi-agent reasoning cluster, and writes structured outputs (sticky notes, connector links, and status tags) directly back onto the live board in real time.

Key Technical Deliverables:

  • Real-time webhook dispatcher receiving board deltas with secure payload normalization.
  • Custom n8n HTTP node bridges executing direct Miro REST API requests to create and connect canvas elements.
  • Multi-turn LLM function-calling chain classifying user intents and synthesizing actionable workflow nodes.
  • Successful live 2.5-minute demonstration pitched directly to judges from Miro and n8n leadership.

Independent Verification & Evidence Sources

  • ✅ Event Organizers: Co-hosted by official engineering teams at Miro (miro.com) and n8n (n8n.io).
  • ✅ Format & Rules: Structured 3-stage loop (Design in Miro → Build in n8n → Write back to Miro) with strict 2.5-minute live pitch demo.
  • ✅ Code & Implementation: Technical patterns documented in blog case study and GitHub.
